# فيديو تحضيري

صفحة ترويجية عمودية بدقة 1080×1920، مدتها 40 ثانية، وتنتج ملف WebM من المتصفح بدون تثبيت مكتبات أو تطبيقات إضافية.

## التسجيل من هاتف أندرويد

1. افتح [tahdiri-brown.vercel.app/promo/](https://tahdiri-brown.vercel.app/promo/) بمتصفح Chrome.
2. اضغط **تسجيل الفيديو** وخلي الصفحة مفتوحة.
3. انتظر 40 ثانية؛ التسجيل ينتهي وينزل ملف `tahdiri-promo.webm` تلقائياً.
4. تلقى الملف بتنزيلات Chrome أو بتطبيق **الملفات** داخل مجلد Downloads.

إذا ما اشتغل التنزيل التلقائي، تأكد أن Chrome مسموح له ينزّل الملفات، وافتح الصفحة من جديد. التسجيل يعتمد على Canvas وMediaRecorder الموجودين بمتصفح Chrome.

للتحويل الاختياري إلى MP4 باستخدام ffmpeg على جهاز يدعمه:

```sh
ffmpeg -i tahdiri-promo.webm -c:v libx264 -pix_fmt yuv420p tahdiri-promo.mp4
```

## تشغيل الصفحة محلياً

افتح `/promo/` عبر خادم ملفات محلي أو بعد نشر الموقع. الصفحة تستخدم الشعار الموجود في `icons/icon.svg` وخط Cairo من Google Fonts مع خطوط احتياطية.
