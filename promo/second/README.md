# تحضيري — الإعلان الثاني، النسخة V3

النسخة المنشورة الجديدة هي `tahdiri-ad-02-v3.mp4`. ملف الإعلان السابق `tahdiri-ad-02.mp4` ومعاينة V2 محفوظان دون تعديل. الفيديو مبني على توقيت التعليق الصوتي الأصلي في `voiceover.srt` ومكس الصوت الأصلي؛ ضُبط مستوى الماستر إلى ‎-15 LUFS مع قمة ‎-1.4 dBTP دون تبديل أو إعادة تسجيل الصوت.

## التسليم

- MP4، H.264 High، AAC stereo 48 kHz
- 1080×1920، 9:16، 30 إطاراً/ثانية، 26 ثانية
- Contact sheet: `tahdiri-ad-02-v3-contact-sheet.png`
- واجهات التطبيق تمثيل بصري مرسوم من مكونات وتسميات المنتج، وليست لقطات شاشة حقيقية.
- في مشهد الوزاريات تظهر حالتها الفعلية «غير متحقق» ولا تُعرض أسئلة أو أرقام مختلقة.

## إعادة بناء المشاهد

ملفات المصادر المختصرة موجودة في `assets/`: لقطتا الدراسة وتقليب الصفحة، ومكس الصوت الأصلي. السكربت `render_ad_v3.py` يرسم إطارات RTL باستخدام خط Noto Naskh العربي، ثم تُحوّل إلى الفيديو بأدوات FFmpeg skill المحلية (`sequence.py`, `audio.py`, `loudness.py`, `look.py`, `probe.py`, `check.py`). مكونات التطبيق وبياناته هي مرجع نصوص الواجهة، وألوان العلامة وشعارها من المستودع.

## الفحص

تم التحقق عبر `probe.py` و`check.py --platform reels`: مدة 26 ثانية، H.264/AAC، 1080×1920، 30fps ثابت، وقياس الصوت ‎-15.0 LUFS / ‎-1.4 dBTP. فحص Reels اجتاز جميع متطلبات التسليم؛ الترجمة الاختيارية غير مضمّنة كمسار منفصل لأن النصوص الحركية ظاهرة داخل المشاهد.
